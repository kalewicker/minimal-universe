# R06e: time-zero admission before assay cost calibration

R06d established a synthetic atomic operator, not an eligible scientific parent
population. Before measuring a 50-event assay's costs, this registration asks
whether that operator is applicable to the original engineering inputs at all.
The original 14 seed definitions suggest no qualifying initial patch. This is a
predeclared admission review; no measured completion result is anticipated or
substituted by assuming a favorable parent generator.

## Frozen population and gate

Use every one of the 969 canonical G2 rules, all five core and nine extra seeds
from R05b in stored order, and lex_first, lex_last, uniform_match. This is 13,566
parent groups and 40,698 parent/scheduler rows, with four prospective orientation
slots per row (162,792 total). No scheduler or law enters eligibility, since the
parent prefix is fixed at zero. Do not add burn-in, grow a seed, replace unavailable
parents, select a subset or shorten the requested 50-successful-event horizon.

These are calibration groups, not independent random parents or a production
registry. Group keys include canonical law identity and seed ID, excluding
scheduler, orientation and prefix. Inherit the existing R02 hash partition; all
four split labels are accounting metadata here. No reserved held-out trajectories
are opened or evaluated.

A patch consists of two distinct disjoint reciprocal dyads, with exactly four
induced internal edge occurrences. Loops, internal cross edges or duplicate dyad
occurrences invalidate the patch; outside attachments and loops are allowed.
Return every eligible patch canonically: sort each dyad's endpoints, then sort
the two dyads. Do not choose among patches by measured outcome. Count-based
bounds are insufficient: the only six-node seed, for example, needs actual
reciprocity checking, not merely a vertex/edge count test.

Full-panel admission requires every parent/scheduler row to have a patch. A
failure is a design limitation, not a failed effect test. Preserve unavailable
rows and all unstarted orientation slots. Completion fraction, assay runtime and
assay storage remain null, since no branch is executed. Report static-check costs
separately. Even a passing admission gate would require a separate execution
registration; this protocol never launches trajectories.

## Independent detector calibration

The implementation enumerates unique reciprocal dyads, tests disjointness and
counts induced occurrences. The independent oracle enumerates ordered assignments
of four vertices and compares the induced arc multiset directly. Compare exact
canonical patch lists on every seed and these preregistered synthetic controls:

- All directed four-node multigraphs with zero through four edges: 4,845 graphs.
  Exactly three have a patch (the three perfect reciprocal pairings).
- All 220 R06c external contexts attached to the standard two dyads. All 220
  remain eligible; the oracle also searches other assignments, not just that patch.

Total: 5,065 control graphs, 223 with eligible patches. Calibration positives are
never inserted into the original seed population. Tests also cover invalid input,
alternate pairings, multiple eligible patches and inside/outside nuisance edges.

## Bounds and custody

One exclusive attempt, 120 seconds and 64 MiB retained output. Source and prior
receipts are SHA-256 pinned before execution. Preserve the full local admission
ledger, all unavailable rows, protocol digest, execution receipt and any failure.
Publish compact reports only. Deterministic clean-source replay is verification,
not a new scientific attempt. No graph transition, score, null draw, hypothesis
test, native kernel change or scientific promotion is authorized.

## Next boundary

If time-zero admission fails, separately register a parent-population design
review. Compare explicit alternatives such as an engineered supplied-state assay
versus an endogenous parent-generation protocol, with distinct interpretations,
frozen eligibility, denominators, partitions and budgets. Do not automatically
execute burn-in or repair the inputs. Full-horizon cost/completion calibration
remains unperformed until an admitted population and execution protocol exist.
