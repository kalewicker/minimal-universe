# R06j synthetic terminal outcome adapter

The adapter validates an explicit parent roster and branch records and returns
exact rational bounds for the outcomes proposed in R06i. The registered
fixture has four parents, two admitted parents and 24 branch slots. All
three scheduler summaries agreed with hand-derived bounds. Fifteen malformed
fixtures were rejected for their registered reasons.
[Registration](../protocols/r06j.json) · [Receipt](r06j.json) · [Fixture](../fixtures/r06j/panel.json)

## Input and output

Each fixture parent supplies a unique key under
`mu/G2-terminal-fixture-v1/`, a positive rational weight as
`[numerator, denominator]`, and an initial graph. Graph snapshots use
`nodes` and an `edges` array of endpoint pairs. The adapter admits parents
with exactly one canonical induced dyad patch. The roster includes separate
entries for parents with no patch and parents with multiple patches.

Each admitted parent supplies four orientation records for each of
`lex_first`, `lex_last`, and `uniform_match`. Orientation IDs 0 and 1
form the target arm. IDs 2 and 3 form the sham arm. Records carry parent
identity, inherited partition, canonical patch, status, verified event count
and endpoint snapshot or null. A missing slot is an input error. An explicit
unstarted slot is an admitted observation category with unresolved bounds.

| Status | Event count | Endpoint | Contribution |
| --- | --- | --- | --- |
| `terminal` | Below 50 | Required, with no eligible ordered path | Exact progress, zero reach and joint indicators |
| `reached` | 50 | Required | Exact progress and reach, joint indicators from the score and graph definedness |
| `reached_snapshot_missing` | 50 | Null | Exact progress and reach, joint indicators in [0, 1] |
| `resource_censored`, `domain_unsupported` | Below 50 | Null | Verified prefix bounds progress, with reach and joint indicators unresolved |
| `not_started` | 0 | Null | Progress, reach and joint indicators in [0, 1] |

The adapter checks terminality directly over distinct edge occurrences.
For reached snapshots it computes the reciprocity score from endpoint pairs.
The fixture includes an empty horizon endpoint and a nonempty endpoint with
score zero. The score-defined joint indicator distinguishes them. A missing
horizon snapshot leaves that indicator unresolved. These supplied records
exercise bookkeeping boundaries. They do not establish trajectory
reachability or verify the origin of a reported event count.

## Aggregation checks

Orientations have equal weight within their arm. The fixture's eligible parent
weights are 1 and 3, normalized within each scheduler. Bounds are averaged
within each scheduler and retain every eligible parent. The complete roster
remains visible, and an empty eligible denominator yields null bounds.

| Scheduler | Weighted progress contrast | Weighted horizon-reach contrast |
| --- | --- | --- |
| `lex_first` | [−13/100, 101/400] | [−5/8, 1/8] |
| `lex_last` | [−2/5, 101/400] | [−5/8, 1/8] |
| `uniform_match` | [−13/100, −49/400] | [−5/8, −1/4] |

All 15 scheduler-by-outcome intervals matched the hand calculations. The
checker also verified invariance to roster and branch order and the no-eligible
case. The example intervals describe constructed records only. The adapter
applied zero graph transitions and scored zero empirical rows. Scientific
status remains untested.
