## Attempt history and evidence

No implementation/test mismatch was observed and no pass threshold or fixture
input changed. There was one explicitly interrupted **engineering execution**:
the original serial sanitizer runner was stopped after 805 completed graph cases
(9,456 events) because instrumented process startup was slow. Its partial trace
remains local and its hash, counts, and interrupted status are recorded in
`r01-sanitize-serial-interrupted.json`. Incomplete work was not counted as passed.

The checker was then changed only to dispatch independent fixture processes
concurrently and serialize their results in the original order. A complete new
release run reproduced the original serial trace exactly. The full concurrent
sanitizer run then matched that new release receipt, including source hashes.
`r01-checker-equivalence.json` records the serial/concurrent comparison.
`source-snapshots/verify_r01_serial.py.txt` preserves the earlier checker bytes
bound by the initial release receipt. All versions and attempts remain distinct.

Current receipts:

- `r01-sanitize-parallel.json`: complete sanitizer validation with current checker.

## Reproduce

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
ctest --test-dir build --output-on-failure
python3 -B -m unittest discover -s tests -v
python3 -B scripts/audit_r00.py --verify reports/r00.json
python3 -B scripts/verify_r01.py --binary build/msru --workers 8 \
  --output results/recheck-release.json --trace results/recheck-release.jsonl \
  --compare reports/r01-release-parallel.json

cmake -S . -B build-sanitize -DCMAKE_BUILD_TYPE=Debug -DMSRU_SANITIZE=ON
cmake --build build-sanitize -j 4
ctest --test-dir build-sanitize --output-on-failure
python3 -B scripts/verify_r01.py --binary build-sanitize/msru --workers 8 \
  --output results/recheck-sanitize.json --trace results/recheck-sanitize.jsonl \
  --compare reports/r01-release-parallel.json
```

Outputs refuse overwrite; use fresh names for another attempt. The checker
compares source and trace hashes, allowing compiler-dependent binary differences.

## Limits and next boundary

Checkpoint replay verifies consistency, not authenticity. The reference kernel
copies graph/history state transactionally and is not optimized for long runs.
Logical-size and depth caps are not a global physical-memory or wall-time budget.
The overflow guard is tested directly; reference ceilings prevent reaching uint64
allocation exhaustion through normal CLI execution. Fixture agreement is finite
evidence, not a proof of universal implementation correctness.

R02 is next: register a measurement-calibration protocol, define bounded motif
semantics, test persistence against the analytical exposure baseline, and freeze
primary outcomes, nulls, effect thresholds, partitions, and promotion gates.
No candidate-selection or downstream discovery is authorized by R01 itself.
