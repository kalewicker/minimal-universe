# R06i terminal outcome design review

The synthetic review passed. The proposed primary outcome is the fraction of
50 successful events completed before verified match exhaustion. It includes
observed early stops and preserves the original horizon-reach measure as a
companion outcome. A separate structural indicator tracks the joint event of
reaching the horizon with a defined reciprocity score at or above a threshold.

| Synthetic comparison | Target minus sham in event progress | Target minus sham in horizon reach |

| Stop at event 2 versus reach 50 | −24/25 | −1 |
| Stop at event 49 versus stop at event 2 | +47/50 | 0 |
| Interrupted after event 49 versus reach 50 | [−1/50, 0] | [−1, 0] |
| Empty versus defined zero, both at event 50 | 0 | 0 |

In the last control, the reached-empty branch has an undefined score. The
defined-zero branch meets threshold zero, so the joint structural contrast is
−1. For a verified nonempty terminal graph the score is exactly zero, since any
reciprocal pair would supply an eligible match. Terminal scores describe
the state at the stop and carry their actual event index.

Each of **10,000 synthetic orientation quartets** matched enumeration of
extremal completions using exact fractions. The checker rejected nine invalid
records. Verified prefixes give componentwise bounds for unresolved branches.
The bounds ignore additional law-specific constraints and use no distributional
assumption about the unresolved outcomes. A recorded event count of 50 with a
missing snapshot requires an additional status before an adapter can ingest it.

This review chose event progress as the proposed primary outcome because it
distinguishes terminal times while retaining all patch-eligible branches.
The earlier scientific question about recovery of reciprocity needs its own
baseline contrast. The empirical R06g panel remains an engineering calibration
with a failed full-panel completion gate. The design checked zero empirical
assay rows and applied zero graph transitions. Scientific status is untested.

The next bounded milestone is a separately registered synthetic bookkeeping
adapter that checks eligibility, group identity, orientation weights,
and endpoint availability. Scientific population selection, inference and
trajectory execution require a separate registration.
